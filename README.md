# NetPulse

轻量的 Windows 网速悬浮窗、流量统计和网络工具箱。所有功能免费，不收集数据，没有广告。

## 功能（v0.5）

### 网速与流量

- **悬浮窗**：实时显示下载和上传速度。
  - 可置顶，可拖动，拖到屏幕边缘会自动吸附。
  - 不抢焦点，也不出现在 Alt+Tab 中。
  - 可锁定位置，也可开启鼠标穿透。
  - 运行全屏游戏、视频或演示时自动隐藏。
  - 有深色和浅色两种主题，默认跟随任务栏。
  - 显示方式可选（v0.4 新增）：两行（下载、上传）、一行，或只显示合计。
  - 可选显示最近 1 分钟的迷你速度曲线（v0.4 新增）。
  - 位置按所在显示器记忆（v0.4 新增）：保存的是到最近屏幕角落的距离，更换分辨率、缩放比例或拔掉显示器后仍会回到合适的位置。
- **托盘图标**：鼠标悬停显示实时速度。单击打开流量统计，右键菜单可直接进入各个页面。
  - 可选把当前下载或上传速度直接画在图标上（v0.4 新增）：最多三个字符，图标底部的横条随单位变长（K 约三分之一，M 约三分之二，G 满格）。
- **流量统计**：显示今天和本周期的用量、30 天柱状图和每日明细，可导出 CSV。
  - 可按网络查看（v0.4 新增）：Wi-Fi 按名称（SSID）统计，其他网卡按网卡名称统计。手机热点等按流量计费的网络可以单独设置套餐，用量达到阈值时单独提醒。
  - 按网络的统计从 v0.4 开始记录，之前的用量只计入“全部网络”。
  - 范围可选最近 7 天、30 天或 12 个月（v0.5 新增）。按月视图按自然月汇总，统计默认保留 400 天，12 个月视图的最早月份可能不完整。
- **提醒**（v0.5 新增，默认关闭，都在设置页的“提醒”中）：
  - 速度持续偏高：上传或下载速度连续超过设定值一段时间后提醒一次，用于发现后台上传；速度降下来之后才会再次提醒。
  - 程序流量：某个程序当天的流量超过设定值时提醒，每个程序每天一次。需要以管理员身份运行（因为数据来自进程流量记录）。
  - 每周摘要：每周一用通知显示上周（周一到周日）的流量和相比前一周的变化，默认开启，可关闭。
- **备份与恢复**（v0.5 新增）：设置页可以把设置和全部统计（总流量、按网络、按程序）保存为一个 JSON 文件，也可以从备份恢复。恢复会替换当前的全部内容并重启 NetPulse。备份只保存在你选择的位置，不会上传。
- **实时速度**（v0.3 新增）：最近 60 秒或 10 分钟的速度曲线，显示当前、峰值和平均速度，鼠标悬停可查看任意时刻的数值。
- **流量套餐提醒**：
  - 可设置每周期流量和每月重置日。
  - 用量达到阈值或超额时各提醒一次。
  - 可选择上传流量是否计入。
- **网卡选择**：可以只看某一块网卡。自动模式默认排除虚拟网卡（VPN、Hyper-V 等），避免重复计算。
- **开机启动**，三种选项：
  - 不启动。
  - 启动：写入当前用户的 `Run` 项，不需要管理员权限。
  - 以管理员身份启动（v0.3 新增）：
    - 通过“任务计划程序”在登录时以管理员身份启动，不弹出权限提示，可以自动记录进程流量。
    - 开启和关闭时各需要确认一次 Windows 的权限提示。
    - NetPulse 会被复制到 `C:\Program Files\NetPulse`，计划任务只运行这份副本，以免这个以管理员身份运行的程序被普通程序替换。
    - 更新版本后，设置页会提供“用当前版本更新已安装的副本”。
- **界面**（v0.3 新增）：
  - 语言可选中文或英文。新安装默认跟随 Windows 显示语言，从旧版本升级的用户保持中文。
  - 主窗口可选深色、浅色或跟随 Windows 应用模式。
  - 两项都在重启 NetPulse 后生效。
- **已修复**（v0.4）：
  - NetPulse 以管理员身份运行时，再次打开 NetPulse 现在会显示主窗口。（从 v0.3 升级后，需要先重启一次正在运行的旧版本才会生效。）
  - 深色模式下，下拉框和数字框改为深色。

### 进程流量（v0.2 新增）

- 实时显示每个程序的下载和上传速度，以及开始记录以来的累计流量。
- **历史记录**（v0.3 新增）：以管理员身份运行时自动记录，按天保存每个程序的流量。可以查看今天、本周期和最近 30 天的排行，并导出 CSV。
- 可以按程序合并，也可以逐个进程显示。
- 数据来源是 Windows 内核网络事件（ETW 提供程序 `Microsoft-Windows-Kernel-Network`），统计 TCP 和 UDP 的收发字节数。
- 这项功能**需要以管理员身份运行**。未提权时，页面上有“以管理员身份重启”按钮。重启后会弹出 Windows 的权限确认，旧的实例退出，新的实例接管。

### Wi-Fi（v0.2 新增）

- **当前连接**：SSID、信号强度（% 和 dBm）、频段和信道、协议（Wi-Fi 4/5/6/7）、安全类型、连接速率、BSSID。
- **已保存的网络**：列出全部网络及其安全类型。
  - 密码只有点击“显示密码”后才会向 Windows 读取，**不会写入磁盘**。
  - 切换到其他网络或离开页面后，密码会自动隐藏。
- **二维码**：用手机扫描即可连接，界面上会提示“任何扫描者都能连接”。
- 直接调用 Windows Native Wifi API（`wlanapi.dll`），不解析 `netsh` 的输出（`netsh` 的输出随系统语言变化）。
- Windows 11 24H2 起，读取 Wi-Fi 连接信息需要开启“位置”权限。被拒绝时，页面会给出打开设置的链接。

### 测速（v0.2 新增）

- 测量延迟（中位数）、抖动、下载和上传速度。下载和上传各用 4 路并行连接，各测约 10 秒，前 2 秒的爬坡阶段不计入。
- 服务器是 Cloudflare 的公共测速端点 `speed.cloudflare.com`，与网页版 speed.cloudflare.com 相同。
- 不发送 Cookie 或任何标识。
- 历史记录只保存在本机。

### 网络工具（v0.2 新增）

- **Ping**：可设置次数，显示每次结果，并统计丢包率和最短、最长、平均延迟。
- **路由追踪**：用 Ping 加递增 TTL 实现，不调用外部命令。可选解析各节点的主机名。
- **DNS 查询**：域名正向解析（A/AAAA 记录），IP 反向解析，并显示系统当前使用的 DNS 服务器。
- **本机网络**：列出各网卡的地址、网关、DNS、MAC 和 DHCP 状态。查询公网 IP 需要手动点击（连接 Cloudflare `1.1.1.1/cdn-cgi/trace`）。

## 隐私

- **平时不联网**：后台运行和统计流量时不发起任何网络连接，实测连接数为 0。
- **只在你主动操作时联网**，且只连接对应的目标：
  - 开始测速 → `speed.cloudflare.com`
  - 查询公网 IP → `1.1.1.1`
  - Ping、路由追踪、DNS → 你输入的目标
- 不收集、不上传任何个人信息。
- 所有数据只保存在 `%LOCALAPPDATA%\NetPulse\`：
  - `settings.json`：设置
  - `usage.json`：每日流量，默认保留 400 天
  - `speedtests.json`：测速历史，最多 50 条
  - `process-usage.json`：每个程序每天的流量。只有以管理员身份运行时才会记录，保留天数与流量统计相同
  - `error.log`：出错时才会生成，只记录在本地
- Wi-Fi 密码从不写入磁盘。

## 构建

需要 .NET 10 SDK。

```powershell
dotnet build NetPulse.slnx
dotnet test NetPulse.slnx
dotnet run --project src/NetPulse

# 发布为单文件 exe（运行时需要 .NET 10 Desktop Runtime）
dotnet publish src/NetPulse/NetPulse.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o publish
```

如果要发布成不依赖 .NET 运行时的版本，把 `--self-contained false` 改为 `true`，代价是体积会大得多（上百 MB）。

开发测试时，可以设置环境变量 `NETPULSE_PROFILE=dev`，或者加参数 `--profile=dev`。测试版会使用独立的数据文件夹（`%LOCALAPPDATA%\NetPulse-dev`）、独立的单实例锁和独立的开机启动项，可以和日常使用的版本同时运行。

## 项目结构

| 路径 | 内容 |
|---|---|
| `src/NetPulse.Core` | 与界面无关的逻辑：速度采样、流量账本、计费周期、套餐提醒、进程速率、测速引擎与统计、Ping 统计、Wi-Fi 配置解析与二维码内容、设置存储（原子写入，文件损坏时自动回退） |
| `src/NetPulse/Platform` | Windows 接口：ETW 内核网络跟踪、Native Wifi、管理员提权重启、以管理员身份开机启动（计划任务） |
| `src/NetPulse` | WinForms 界面：悬浮窗、托盘、主窗口（流量统计、实时速度、进程流量、Wi-Fi、测速、网络工具、设置） |
| `tests/NetPulse.Core.Tests` | xUnit 单元测试，包括一个用本地假服务器离线跑通完整测速流程的测试 |

第三方依赖只有 [QRCoder](https://github.com/codebude/QRCoder)（MIT 许可），只用它生成二维码矩阵，绘制由本项目完成。
